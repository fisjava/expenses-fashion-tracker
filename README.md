# Expenses-Fashion-Tracker

A Java Spring Boot application that helps fashion designers track business income, expenses, assets, customers, orders, and reports to understand business profitability.

## Technologies Used

- Java
- Spring Boot
- MySQL
- Maven
- Thymeleaf, HTML, and CSS

## Main Features

- Manage business assets and locations.
- Manage customer records.
- Record income and expenses.
- Manage business orders.
- Generate business reports.

## Database Setup

The application uses a MySQL database named expensetracker_db.

Configure your local database connection in src/main/resources/application.properties before running the application.

The original database dump containing customer information and transaction records is excluded from this repository.

## Running the Application

1. Install a compatible Java Development Kit and MySQL.
2. Create the expensetracker_db database in MySQL.
3. Configure the database connection in application.properties.
4. Open the project in a compatible Java IDE or run it using the Maven wrapper.
